# Официант — деньги (Android)

Android-проект с автоматической сборкой APK через GitHub Actions.

## Самый простой путь с телефона

1. Создай аккаунт GitHub и новый пустой репозиторий.
2. Загрузи содержимое этой папки в репозиторий (можно через сайт GitHub в браузере).
3. Открой вкладку **Actions**.
4. Выбери workflow **Build APK** и нажми **Run workflow**.
5. После завершения открой запуск workflow → **Artifacts** → `WaiterMoney-debug-apk`.
6. Скачай ZIP, распакуй его и установи `app-debug.apk`.

При первой установке Android может попросить разрешить установку приложений из браузера/файлового менеджера.

Для обычного личного использования debug APK подходит. Данные приложения хранятся локально на телефоне.
